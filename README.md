# Sangeet Sangai

Sangeet Sangai is a real-time synchronized collaborative music listening platform.

Users can create temporary music rooms, share a room code, join from different locations, upload music temporarily, and listen together with synchronized playback.

## Planned Features

- Create and join music rooms
- Unique room codes
- Real-time participants
- Temporary music uploads
- Shared music queue
- Synchronized play and pause
- Synchronized seek and skip
- Automatic room cleanup
- WebSocket-based real-time communication
- Future mobile application support
